# External 3D waterfall teacher

This pipeline produces an **independent** 3-D DFSPH waterfall teacher with
[SPlisHSPlasH](https://github.com/InteractiveComputerGraphics/SPlisHSPlasH).
It is not generated by the Phase 2 WCSPH solver and can therefore be used as
an external validation/training source.

## Terrain choice

For final experiments use a cropped **USGS 3DEP 1 m DEM GeoTIFF**. The DEM is
the scientific collision source. A texture/photogrammetry asset may be added
later for rendering, but must not silently replace the collision geometry.

Two OBJ meshes are generated:

- `terrain_collision.obj`: smoothed 129×129 watertight mesh for SDF collision.
- `terrain_visual.obj`: 385×385 watertight mesh for the viewer/Unreal.

The included deterministic natural-cliff mode is only an immediate pipeline
test; it is not claimed to be surveyed terrain.

## Commands

```powershell
.venv-gpu\Scripts\python.exe -m phase3.external_teacher.terrain_pipeline
.venv-gpu\Scripts\python.exe -m phase3.external_teacher.build_scene
```

For a downloaded USGS GeoTIFF (requires `pip install rasterio`):

```powershell
.venv-gpu\Scripts\python.exe -m phase3.external_teacher.terrain_pipeline `
  --dem phase3\external_teacher\source\usgs_cliff_1m.tif `
  --length 80 --width 60
```

SPlisHSPlasH Python wheels support Python 3.6–3.10 on Windows, whereas this
project currently uses Python 3.12. Use a separate Python 3.10 environment or
the compiled `SPlisHSPlasH.exe`; do not downgrade `.venv-gpu`.

Run through the wrapper. It stages files under an ASCII-only temporary path,
because the current Windows SPlisHSPlasH build cannot open the Korean workspace
path directly:

```powershell
.venv-gpu\Scripts\python.exe -m phase3.external_teacher.run_splish --smoke
.venv-gpu\Scripts\python.exe -m phase3.external_teacher.run_splish --seconds 18 --keep-stage
.venv-gpu\Scripts\python.exe -m phase3.external_teacher.run_splish --gui --seconds 30 --keep-stage
```

Particle export and conversion to the project's trajectory NPZ schema are the
next pipeline stage, after the executable is installed and its export format
has been smoke-tested on this machine.
